# Material de Estudo - Transpetro

Este repositório contém o material de estudo para a área de atuação da Transpetro, estruturado em um documento em HTML para leitura e impressão.

## Conteúdo

- Documento principal: `Material de Estudo - Transpetro.html`
- Formato: página estática em HTML com visualização adaptada para leitura e impressão em A4
- Tema: conteúdo de estudo relacionado à "Ênfase 5" da Transpetro

## Como abrir

1. Abra o arquivo `Material de Estudo - Transpetro.html` em qualquer navegador moderno.
2. Para visualização em tela, basta clicar duas vezes no arquivo ou abrir pelo navegador.
3. Para impressão em PDF, use a opção de impressão do navegador e escolha "Salvar como PDF".

## Estrutura do material

O arquivo inclui:

- títulos e seções organizadas por assunto
- textos explicativos em formato de estudo
- listas e tabelas para facilitar a revisão
- layout preparado para impressão em papel A4

## Observações

- O material foi preparado para estudo e revisão de conteúdos específicos.
- Se necessário, pode ser atualizado ou reorganizado conforme novas referências forem adicionadas.
